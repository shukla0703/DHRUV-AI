# DHRUV AI UI Theme

## Brand Direction

DHRUV AI should feel like a celestial navigation system for action-oriented intelligence:

- precise, luminous, and directional
- premium and high-trust rather than noisy sci-fi
- dark-space surfaces with electric blue guidance lines
- white star-core highlights for clarity and confidence

## Dashboard Theme

- Hero panel: logo-first, strong midnight gradient, crisp white/cyan typography
- Core presence: glowing star-core visual with orbital rings inspired by the provided mark
- Memory vault: dark glass panel with structured, readable history blocks
- Command console: high-contrast input, strong primary CTA, compact action grid
- Metrics: compact observability cards with restrained glow accents

## Button Language

- Primary button: electric blue fill with white text for actions that trigger the assistant
- Secondary button: darker navy surface with cyan border treatment for utility actions
- Danger button: muted berry-red for wake-mode disarm or destructive-feeling state changes
- Hover state: cyan-lift overlay, not generic brightness-only hover
- Pressed state: deeper blue compression state

## Typography

- Product name: bold geometric sans
- Section labels: uppercase tracking with cyan accent
- Body copy: neutral UI sans optimized for readability
- Avoid novelty futuristic fonts in controls; use them only in display treatments if added later

## Motion Guidance

- Slow orbital motion around the core presence
- Ribbon-wave motion for voice state
- Light panel refreshes instead of constant flashing
- Memory updates should feel calm and deliberate

## Logo Usage

- Use the supplied logo as the hero brand mark
- Keep a clean safe area around the star emblem
- Do not recolor the logo away from its white/cyan palette
- Backgrounds behind the logo should stay deep navy to preserve contrast
